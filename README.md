# 쏙비서 APK 내려받기

이 저장소는 **비공개**입니다. 폰에서 GitHub에 로그인한 브라우저로 받으세요.

## 폰에서 받는 방법

1. 폰 브라우저(크롬, 삼성 인터넷)에서 GitHub에 로그인합니다.
2. 아래 목록의 파일 이름을 눌러 엽니다.
3. 화면의 **다운로드(Download raw file)** 버튼을 누릅니다.
4. 받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 허용 창이 뜨면 허용합니다.
