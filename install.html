처음 설치

  1. 위 버튼을 눌러 파일을 받습니다. 카톡에서 열었다면 ⋮ → 다른 브라우저로 열기 후 받으세요.
  2. 받은 파일을 누릅니다.
  3. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켭니다.
  4. Play 프로텍트 경고가 뜨면 세부정보 → 무시하고 설치를 누릅니다. 이 페이지에서 받은 파일에만 하세요.
  5. 설치가 끝나면 앱을 열고 위치(정확한 위치를 켠 채로)·캘린더 권한을 허용한 뒤, 설정에서 집·회사를 등록합니다.
  6. 마지막으로 "출처를 알 수 없는 앱 설치" 허용을 다시 끕니다.

업데이트

같은 방법으로 새 파일을 설치하면 지우지 않고 그대로 업데이트되며 설정이 남습니다.

화면에 DEBUG 표시가 있는 테스트 버전이 깔려 있으면 업데이트되지 않습니다. 앱을 지운 뒤 설치하세요(설정은 다시 해야 합니다).
