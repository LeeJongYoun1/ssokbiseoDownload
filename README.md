## 설치/업데이트 방법
1. 위 링크를 눌러 APK 파일을 내려받습니다. (카톡에서 링크를 열었다면 ⋮ → **다른 브라우저로 열기**)
2. 내려받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다 (Chrome 또는 내 파일 앱).
4. Play 프로텍트 경고가 뜨면 **세부정보 → 무시하고 설치**를 누릅니다. (**이 페이지에서 받은 파일에만** 하세요. 다른 곳에서 온 파일은 경고를 무시하지 마세요.)
5. 설치가 끝나면 **설정 → 애플리케이션 → (Chrome 또는 내 파일) → 출처를 알 수 없는 앱 설치**를 다시 끕니다.

## 업데이트
- 예전 정식 버전(1.0.x)을 쓰고 있어도 위 파일을 설치하면 그대로 업데이트되고 설정(집·회사 등)은 남습니다.
- 화면에 **DEBUG** 표시가 있는 테스트 버전이 깔려 있다면 서명이 달라 업데이트되지 않습니다. 앱을 지운 뒤 설치하세요(설정은 다시 해야 합니다).

## 진짜 쏙비서 파일인지 확인하기 (선택, 고급)
쏙비서 APK는 아래 인증서로 서명되어 있습니다. 서명이 다르면 쏙비서가 아닙니다.

- 인증서 SHA-256: `02:03:47:B9:A3:CA:1E:A7:28:CE:DB:E8:67:FD:38:62:AD:86:4C:A7:39:B9:0E:3A:12:6B:1F:62:35:DA:36:A1`

- 이미 쏙비서가 깔린 휴대폰은 서명이 다른 파일을 업데이트로 받아 주지 않습니다.
