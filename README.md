# 쏙비서 APK 내려받기

이 저장소는 **비공개**입니다. 폰에서 GitHub에 로그인한 브라우저로 받으세요.

## 폰에서 받는 방법

1. 폰 브라우저(크롬, 삼성 인터넷)에서 GitHub에 로그인합니다.
2. 아래 목록의 파일 이름을 눌러 엽니다.
3. 화면의 **다운로드(Download raw file)** 버튼을 누릅니다.
4. 받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 허용 창이 뜨면 허용합니다.

  - 크기 90,565,205바이트, sha256 `0c7a7f7e3295ae11f8eb36b18519573655aa16ec27f7f76f8763a073a2f37194`
  - 새로 들어간 것: 뉴스·소식·기분 조언(브리핑)을 **서버를 거쳐** 받습니다(`ssokbiseo` 저장소가 비공개가 되어 옛 방식이 막혔기 때문). 기본 서버 주소가 운영 서버라 **날씨·길찾기도 실제 값**이고 노란 "예시 화면" 띠가 없습니다. 미세먼지 줄은 서버에서 에어코리아 승인이 끝나면 나타납니다.
  - 앱 안에 서버 키가 없습니다(설치마다 서버가 임시 번호를 발급하는 방식).
  - **debug 서명**입니다. 폰에 이미 깔린 1.0.15·1.0.16 **테스트 빌드**(화면에 DEBUG 표시가 있는 것) 위에는 업데이트로 설치됩니다(서명이 같음을 확인).
  - 아래 **정식 빌드가 깔려 있으면 서명이 달라서 설치되지 않습니다.** 그 앱을 지운 뒤 설치해야 하고, 그러면 설정과 집·회사 정보가 사라집니다.
